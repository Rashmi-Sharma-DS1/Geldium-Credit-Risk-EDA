# 📊 TATA Data Analytics Job Simulation — Exploratory Data Analysis (EDA)

### 🔗 Program: TATA Data Analytics Job Simulation (Forage)  
This repository contains **Task 1: Exploratory Data Analysis (EDA)** for the TATA–Forage virtual job simulation.  
The project focuses on performing a detailed EDA for **Geldium**, a financial services client aiming to improve its **credit delinquency prediction model**.

---

## 🚀 Project Overview

Geldium is working towards a more **data-driven and AI-enabled risk assessment strategy**. Their current process relies heavily on historical trends and coarse segmentation, which limits their ability to **identify at-risk customers proactively**.  

To support this initiative, TATA iQ's Analytics team has been assigned to analyze Geldium’s dataset before any predictive model can be developed.

As part of the simulation, I completed **Task 1: Exploratory Data Analysis**, focusing on:

- Assessing dataset completeness  
- Identifying inconsistencies or missing data  
- Discovering patterns and early risk indicators  
- Ensuring the dataset is suitable for downstream predictive modeling  
- Generating actionable insights using GenAI tools while safeguarding data confidentiality  

---

## 🎯 Objectives Assigned by Senior Manager (Charithra)

- ✔️ Review dataset structure, completeness, and key attributes  
- ✔️ Identify missing values or inconsistencies affecting prediction quality  
- ✔️ Apply GenAI tools for insight extraction (without exposing sensitive financial info)  
- ✔️ Summarize anomalies, correlations, and potential risk indicators  
- ✔️ Draft a structured EDA report to guide later modeling phases  

---

## 🧠 Why This Task Matters

This phase ensures that the **foundational data is reliable**, enabling TATA and Geldium to build:

- Accurate prediction models  
- Stronger customer-level insights  
- Better delinquency intervention strategies  

The results of this EDA will be reviewed by the broader Analytics team and Geldium’s leadership, influencing the next stages of the credit risk project.
